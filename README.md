## 流量型和带宽型，先分清再下单

这张表里的套餐实际上是两种东西。

MOLite-Mini、Starter、Standard、Pro 和 JPIIJ 两个套餐属于流量型：带宽 1000M 到 2000M，每月给一个流量额度，从 1000G 到 30000G 不等。你跑多少算多少，额度用完就没了。

MOLite-高级竞技A 和 B 属于带宽型：带宽直接给到 10000M，流量栏标 0G/月。

选哪种取决于你的用法。放网站、跑 API、做轻量服务，流量型足够，2500G 对个人站点是很宽裕的数字。需要持续大流量传输、做下载或者对带宽峰值敏感的业务，才需要考虑高级竞技系列。多数人买 10000M 带宽的机型，用不上那么多带宽，多花的钱在账单上体现，在体验上体现不出来。

还有一笔账要算清楚。MOLite-Mini 和 JPIIJ-Lite 都是 24.99 元/月，差在流量和线路归属：前者 2500G，后者 1000G 但走日本线路。如果你的服务对象在东亚，JPIIJ 的线路价值可能高过那 1500G 流量；如果只是自己用，MOLite-Mini 更划算。

## 三条会直接影响使用的限制

轻云服务器购买页明确写出的规则有三条，每一条都会影响你怎么买。

**流量只算出站。** 入站流量不计费，这意味着接收数据、被访问这类行为不消耗你的额度，只有往外发才扣。

**流量用完自动停机，且流量不能重置。** 不是限速，是停机。这一点和 DMIT 那类“超额后限速到 100Mbps 至 1Gbps、月底自动恢复”的处理方式完全不同。买流量套餐时，额度要按峰值月份估，不是按平均月份估。

**配置不能原地升级。** 这条最容易被忽略。买小了不能加钱升配，只能重新买一台。所以第一台机器宁可多留 20% 余量，也别卡着最低配买。
